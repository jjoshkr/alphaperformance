# 수익화 채널별 사업자·세금 구조 (2026-11-23 정리, 세무사 확인 전 초안)

> 일반 정보 정리이며 세무·법률 자문이 아니다. 등록 전 세무사(온라인 무료 상담: 삼쩜삼·토스 세모 등)에게 한 번 확인한다.

## 결론 한 줄
**디지털 상품(PDF)·제휴 수수료·인스타 구독/기프트는 지금 바로 사업자 없이 시작 가능.**
**물건을 직접 파는 스마트스토어·쿠팡은 사업자등록 + 통신판매업 신고가 필수.** 아마존은 파는 나라(미국/독일)에 따라 다르다.

## 권장 구조 (단계)
**1단계 (지금~첫 매출):** 사업자 없이 시작. Payhip PDF, 파트너 제휴 링크, 인스타 구독·기프트 켜기. 수입·지출 기록(스프레드시트)만 해 둔다.

**2단계 (월 매출 50~100만원 또는 물건 직접 판매 시작):** **사용자님 명의 한국 개인사업자** 등록 (홈택스, 무료, 당일~1일).
- 업종: ① 전자상거래 소매업(525101) ② 1인 미디어 콘텐츠 창작자(940306, 면세) 또는 미디어콘텐츠창작업(921505, 과세). 광고·협찬·판매가 섞이면 과세사업자(921505 + 525101)가 단순. 세무사와 결정.
- 과세 유형: 연 매출 1억400만원 미만이면 **간이과세자**(부가세 부담 작음, 세금계산서 발행 제한). 기업 협찬을 받으려면 일반과세가 편할 수 있음.
- 이어서 **통신판매업 신고** (정부24, 등록면허세 연 4만원 내외, 간이과세자는 면제 가능) → 스마트스토어·쿠팡 입점.
- 법적으로는 사업 개시 20일 이내 등록이 원칙. 실무에서는 수익이 정기화되는 시점에 한다.

**원우 님 몫(독일 거주):** 독일 거주자의 소득은 독일에서 과세. 한국 사업자는 사용자님 명의로 하고, 원우 님에게는 **용역비/수익배분**으로 지급 → 원우 님은 독일에서 Freiberufler/Gewerbe로 신고. 한·독 이중과세방지협정이 있어 이중 과세는 피할 수 있으나 양국 신고가 필요. Amazon.de·독일 대면 세션은 원우 님 독일 사업자 쪽에 두는 게 자연스럽다.

**3단계 (해외 물류):** 아마존은 '물건 직접 판매'라 재고·물류·반품이 생긴다. 파트너 물품이라면 아마존에서 **파는 것보다 Amazon Associates(제휴)로 소개**하는 편이 재고 없이 가능. 자체 상품(굿즈·프린트 PDF)이 생기면 그때 FBA 검토.

## 바로 할 일
1. 인스타 대시보드 → 수익화 도구 → **크리에이터 구독** 켜고 가격·혜택 설정(월 $4.99 수준, 주간 세션 1개 + Q&A). 지급 계정 등록.
2. 쿠팡 파트너스 가입(국내 팔로워용) + 파트너 자체 제휴 조건 확정.
3. 수입·지출 기록 시작 (`docs/finance/` 스프레드시트).
4. 매출이 월 50만원을 넘기 시작하면 세무사 상담 → 사업자등록 + 통신판매업 신고 → 스마트스토어.
