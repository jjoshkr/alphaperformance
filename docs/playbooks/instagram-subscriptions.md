# 인스타 크리에이터 구독 — 설정·수익 구조·구독자 콘텐츠 (2026-11-23)

## 1. 켜는 순서 (앱, 15분) — 대시보드에 이미 '구독 ✓'
프로필 → 프로페셔널 대시보드 → 수익화 도구 → **크리에이터 구독** → 관리:
1. **정산 계정**: Meta 지급 계정 만들기 → 본인 정보, 은행 계좌(한국 계좌 가능), 세금 정보(비미국인: W-8BEN 전자서명). 사업자등록 불필요, 개인 명의로 가능.
2. **구독 상세 정보**: 가격 선택(메타가 정한 단계 중 선택: $0.99 / 1.99 / 2.99 / 4.99 / 9.99 … $99.99) → **$4.99**로 시작. 혜택 설명 3줄 입력(아래 문구).
3. **콘텐츠 설정**: 구독자 전용 게시물·릴스·스토리·라이브·채널(브로드캐스트)·배지 중 켤 것 선택 → 전부 켜기.
4. **환영 릴스**: 구독 직후 자동 노출되는 20초 영상(원우 님 인사 + 이번 주 세션 예고).
5. **홍보 릴스**: 비구독자에게 "구독하면 이런 걸 받는다"를 보여 주는 릴스 1개 지정(Doué 같은 메커니즘 릴스 끝에 구독 CTA).
6. **구독 미리 보기**: 구독자 전용 게시물 중 비구독자에게 살짝 보여 줄 것 1~2개.

## 2. 수익 구조와 수수료
- 결제: 팔로워가 앱 안에서 월 구독 → Apple/Google이 **인앱 수수료 약 30%** 차감 → Meta는 현재 **0%**(약관상 나중에 받을 수 있음) → 크리에이터 몫 약 **70%**.
  - 예: $4.99 × 100명 = $499/월 → 실수령 약 $350/월 (세전)
- 지급: 월 1회, 전월 수익을 Meta Pay(일부 지역 Stripe)로 등록 계좌에 송금. 최소 지급액은 소액($5~25 수준, 지역별 상이).
- 세금: 해외 플랫폼 소득 → 한국 거주자는 5월 종합소득세에 사업소득으로 신고. 사업자등록은 당장 불필요(정기화되면 등록 권장, `business-setup.md`).
- 구독자는 언제든 해지 가능. 첫 달 유지율이 핵심 지표.

## 3. 구독자에게 줄 것 — 채널 스타일에 맞춘 패키지
**이름: "Return-to-Sprint Lab"** ($4.99/월) — 공개 피드가 "왜 다쳤나"를 보여 준다면, 구독은 "그래서 나는 뭘 하나"를 준다.

| 요일 | 구독자 전용 | 형식 | 제작 시간 |
|---|---|---|---|
| 월 | **이번 주 세션** — 공개 릴스 3동작의 '전체 버전'(세트·휴식·진행 기준, 15~20분 루틴) | 릴스 1개(2~3분) + 캡션에 루틴표 | 30분 (공개 촬영분 재활용) |
| 수 | **메커니즘 풀버전** — 공개 캐러셀의 뒷이야기: 왜 이 동작에서 다치는지, 어떤 선수가 예방 훈련으로 돌아왔는지, 원우 님 코칭 케이스 | 구독자 전용 게시물(캐러셀) | 20분 |
| 금 | **Q&A** — 구독자 채널(브로드캐스트)에서 질문 받고 음성/영상으로 답 | 브로드캐스트 채널 | 20분 |
| 월 1회 | **라이브 폼 체크** — 구독자가 보낸 스프린트/착지 영상 3~5개 리뷰 | 라이브 30분 | 30분 |
| 상시 | 구독자 배지, 댓글 우선 답변, PDF 상품 30% 할인 코드 | — | 0 |

혜택 설명 문구(앱 입력용, EN): `Weekly full speed & rehab session (15-20 min) · Injury mechanism deep-dives · Friday Q&A · Monthly live form check · 30% off all programs`

**왜 이 구성인가:** 공개 콘텐츠에서 이미 만든 소재를 '전체 버전'으로 확장하는 구조라 추가 촬영이 거의 없다. 구독자가 가장 바라는 건 "내 상황에 맞춰 뭘 하면 되나"이고, 그걸 주는 건 Q&A와 폼 체크뿐이다(벤치마크 중 e3rehab·niklas가 멤버십에서 쓰는 형식).

**환영 릴스 대사(KO, 더빙용):** "구독 고마워요. 매주 월요일 이번 주 세션 전체 버전, 수요일엔 부상 메커니즘 뒷이야기, 금요일엔 질문 받아서 답할게요. 첫 질문은 지금 채널에 남겨 주세요."

## 4. 지표와 목표
- 3개월: 구독자 100명(팔로워의 0.5%) → 세전 약 $350/월
- 보는 숫자: 구독 전환(홍보 릴스 조회 → 구독), 첫 달 유지율(>70%이면 양호), Q&A 참여 수
- 구독자 피드백이 다음 PDF 상품의 주제가 된다

## 5. 자동화 후보 (사용자 피드백 대기)
- 월요일 주간 기획에 **구독자 전용 슬롯 2개(월 세션 풀버전, 수 딥다이브)** 추가 → 대사·캡션 자동 생성
- 금요일 Q&A 질문을 텔레그램으로 모아 주고, 답변 초안(원우 님 검토용) 생성
- 구독자 수·수익은 공식 API로 안 나옴 → 월 1회 '대략적인 수익' 화면 캡처 → 수익 문서 갱신
