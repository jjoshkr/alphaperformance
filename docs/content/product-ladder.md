# PDF 상품 구조 — 단품 vs 구독자 전용 (2026-11-23)

## 원칙: 단품은 "완성된 프로그램", 구독은 "이번 주·이번 달의 적용"
| | 단품 PDF (Payhip, 1회 결제) | 구독자 전용 (Instagram 구독 $4.99/월) |
|---|---|---|
| 성격 | 영구 보관하는 **교과서**: 6주 과정, 부위별 복귀 플랜 | 매주 바뀌는 **실습지**: 이번 주 세션 카드, 이달의 부상 메커니즘 |
| 분량 | 30~60쪽, 영상 링크, 테스트 기준 | 1~6쪽, 그 주에만 의미 있는 내용 |
| 수명 | 영구 (업데이트 무료) | 월별 교체, 지나면 아카이브에서만 |
| 가격 | $15~49 | 구독에 포함 + 단품 30% 할인 코드 |
| 절대 섞지 않을 것 | 구독자에게 단품 PDF를 통째로 주지 않는다 | 단품 구매자에게 구독 콘텐츠를 주지 않는다 (할인·우선 응대만) |

## 1. 단품 PDF (교과서)
### 6-Week Speed Program → **2.0으로 업그레이드, $29** (기존 구매자 무료 업그레이드)
지금 $20 버전이 평범해 보이는 이유: "6주 운동표"로 읽힌다. 2.0은 **측정 → 처방 → 재측정**이 있는 프로그램으로:
1. **Baseline 테스트 (Day 0)**: 10m·30m 스프린트(폰 타이머 앱 사용법), 단일 다리 홉 3종, 505 방향전환 → 결과에 따라 **Level 1/2/3** 배정
2. 6주 × 4세션, 레벨별 세트·강도 (3개 트랙)
3. **모든 드릴에 코치 시연 영상**(QR/링크, 10~20초)
4. 주차별 **"오늘의 큐 한 줄"** + 흔한 실수 사진
5. **Week 3·6 재측정**과 다음 단계 안내 (→ 구독 또는 Level 업)
6. 부록: 10분 워밍업, 경기 전날·당일 루틴, 부상 신호 체크리스트
7. 인쇄용 **세션 카드**(A5) 24장

### Return-to-Sprint 가이드 (부위별, 각 $15 / 3종 번들 $35 / 스피드 2.0 + 3종 $49)
햄스트링 → 사타구니 → 발목 순으로 제작. 구성: 어디·무슨 근육(해부 일러스트) → 3단계 × 운동 + 세트 + 영상 → **단계 통과 테스트**(예: 단일 다리 브리지 30회 통증 0, 20m 90% 스프린트 통증 0) → 재발 방지 주 1회 루틴 → 언제 병원에 가야 하나. "의료 조언 아님" + 진단 후 사용 문구.

### 무료 리드 마그넷: "First 3 Steps Checklist" (2쪽)
댓글 SPEED → DM으로 전달 → 이메일/텔레그램 수집 → 2.0 출시 때 알림.

## 2. 구독자 전용 PDF (실습지)
| 주기 | 이름 | 분량 | 내용 | 제작 |
|---|---|---|---|---|
| 매주 월 | **Session Card** | 1쪽 | 이번 주 공개 릴스 3동작의 전체 루틴(세트·휴식·레벨별) + 체크박스 | 기획 자동화가 초안 생성 |
| 매월 1일 | **Lab Notes** | 4~6쪽 | 이달의 프로 부상 3건 메커니즘 + 예방 루틴 1개 + Q&A 베스트 5 | 부상 알림·Q&A에서 자동 취합 |
| 분기 | **Case File** | 6~8쪽 | 코치의 실제 코칭 케이스(동의 하에, 익명) before/after | 수동 |
| 상시 | 할인 코드 `LAB30` | — | 단품 30% | Payhip 쿠폰 |

구독자 PDF는 **구독자 전용 게시물의 캡션 링크(Payhip 무료 상품, 비밀번호)**로 배포. 인스타 구독 자체에 파일 첨부 기능이 없기 때문.

## 3. 구매 경로 요약
- 가볍게 시작 → **구독**($4.99): 매주 할 것을 받는다
- 제대로 하고 싶다 → **스피드 2.0**($29): 테스트하고 레벨 맞춰 6주
- 다쳤다/다쳤었다 → **부위별 가이드**($15): 단계·테스트대로 복귀
- 둘 다 → **번들**($49) + 구독으로 유지

## 4. 제작 순서
1. 햄스트링 Return-to-Sprint 가이드 (Doué·Rodri 트래픽 수용, 2~3일)
2. 스피드 2.0 (기존 콘텐츠 + 테스트 프로토콜 + 영상 촬영, 1~2주)
3. 구독 켜는 날부터 Session Card 매주 (자동 초안)
4. Lab Notes 12월 1일 1호
