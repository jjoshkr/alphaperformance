## 4. 숫자 목표 (현재 데이터로 역산, 매주 갱신)
- 현재: 프로필 방문 월 1,700, 링크 클릭 0 → 링크 복구 직후. 기준선은 11월 데이터로 다시 잡는다.
- 1단계 목표(3개월): 페이지 방문 월 500 × 전환 2% = **월 10건 × 평균 $25 = $250/월** + 제휴 $50
- 2단계(6개월): 월정액 100명 × $6.99 = $700/월 + 단품 $400 + 제휴·1:1 $300 = **약 $1,400/월**
- 각 단계의 병목(방문 / 전환 / 객단가)은 Hotjar(`src_*`, `paypal_click`, `gear_buy_*`)와 인스타 인사이트(주간 자동 수집)로 추적

## 5. 매주 자동 갱신되는 것 / 사람이 정하는 것
- 자동: 어떤 패턴이 조회·저장을 만드는지(우리+벤치마크), 어떤 CTA에서 클릭이 나는지(Hotjar) → 주간 기획의 슬롯 배분과 CTA 키워드
- 사람(원우 님·사용자님): 상품 제작 순서, 가격, 파트너 조건, 월정액 시작 시점
